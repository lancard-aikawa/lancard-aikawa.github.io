- スマホから使う: スマホのブラウザから、ドックの中のツールを見て操作できる。ドックはスマホの画面の大きさ (縦・横) に合わせて変わる。
  「設定」で入り切りし、合言葉入りの URL をコピーして開く。家の Wi-Fi か Tailscale の中で使う。
  「スマホから使う: アドレスと状態...」の画面で、待ち受けるネットワーク (Wi-Fi・Tailscale など) を選び、
  待ち受けの状態・アドレス・つないでいるスマホを見られる。つなぐ URL の QR コードを出し、スマホのカメラで読んで開ける。
  つないでいる間 (ドックは PC の画面の外に移る) は、PC の画面の右下に「スマホで使用中」と「PC で使う」ボタンを出す。
  スマホの側で表示倍率を変えられる (ドックの帯の「− 縮小」「+ 拡大」。50〜150%)。
  スマホの日本語の入力 (変換して確定。カタカナ・「。」「ー」も) と絵文字を、Tk でないツール (Mery など) にも正しく打てる。
  ツールの中から開いたメニュー (Mery のメニューの帯など) と小窓 (Mery の検索など) はスマホの画面に出て、押して選べる
  (PC の画面には出ない。小窓は切ると元の位置に戻る)。iPad の日本語の入力も崩れずに打てる。
  つないでいる間に開いた窓 (ツールが開いた VS Code・ターミナル・エクスプローラーなど) は、どのアプリのものでもタブにしてスマホに出す。
  noVNC の「Ctrl」「Alt」とキーの組み合わせ (Ctrl+S・Ctrl+C・Ctrl+V など) と、Shift+矢印などが効く。
  noVNC のクリップボードの欄が PC のクリップボードとつながり、日本語の文字も写して貼れる。
  noVNC の「追加のキー」(Ctrl・Alt など) の絵が出ず、丸が 6 つ並ぶだけだったのを直した。
  スマホの帯の「+ 開く」で、ツールの起動・切り替えと、選んでいるツールを閉じることができる。
  タブが多くても帯の右端のボタン (「+ 拡大」) が切れない。別のタブに切り替えたあと、前のツールの小窓 (Mery の検索など) が
  ドックに重なって、その下を押せなかったのを直した。
- 最大化した窓や、タブにしたあとで自分で最大化する窓 (VS Code) が、画面いっぱいのままドックに重なり、スマホでは帯ごと
  隠れたのを直した。最大化を解いてドックに収め、ドックから外すと最大化に戻す。
- VS Code をタブにすると、ほかの VS Code の窓までスマホの画面に重なり、帯ごと隠れたのを直した (VS Code はどの窓も
  1 つのプロセスなので、ツールの小窓と見ていた)。タブにしていない窓は重ねず、つないでいる間に開いた窓は別のタブにする
- スマホから Mery の文書のタブを押すと、タブが外へ引き出されて別の窓 (別のタブ) に分かれたり、ほかのタブを押しても
  切り替わらなくなったりしたのを直した。ツールのタブの帯を押したときは、そのタブを選ばせる
- スマホから使う: 通信を HTTPS で暗号化できる (「スマホから使う」の画面の「通信を暗号化する」)。証明書は WinTabDock が作り、
  スマホには、画面の「証明書を入れる」の QR コードで開くページから一度だけ入れる (家の中と Tailscale のアドレスにだけ効く)
