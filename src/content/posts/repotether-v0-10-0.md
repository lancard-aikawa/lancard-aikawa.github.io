- 上部のタブに「脆弱性」を足す (これまでは設定の中のタブ)。LockWatch の結果をプロジェクトごとに並べ (深刻度ごとの数・注意・照合した時刻。重いものが多い順)、
  行を押すと状態タブでそのプロジェクトの詳細パネルの「脆弱性」タブを開く。緊急・高の数をタブに出す。
  LockWatch の場所と状態もこのタブに移し、場所はこのタブの「保存」で反映する (設定タブの保存とは別)
- 上部のタブの並びを「状態 / 履歴 / 日報 / 脆弱性 / グラフ / 設定」にする (グラフを後ろへ)
- 詳細パネルの「リポジトリ」タブから pull できる。「pull する」は `git pull --ff-only` (早送りだけ。マージコミットを作らず、競合も起こさない) をして、
  そのリポジトリだけを読み直す。同じタブに未コミットの変更 (競合・ステージ済み・変更・未追跡・stash の数) を出し、「読み直す」で最新にできる。
  未コミットの変更と重なるときは git が何も変えずに止まり、理由を出す。追跡先が無い・分岐しているときなどは押せない。pull のあいだは更新 (自動も) を待たせ、結果は別のプロジェクトへ切り替えていても通知する
- 状態タブの見せ方に「セル」を足す。Windows のエクスプローラの「大アイコン」のように、アイコンと名前のマスを並べる。
  分類が「フォルダ」「タグ」のときは、階層の見出しの中にマスを並べる (タグではマスをドラッグして付け替えられる)
